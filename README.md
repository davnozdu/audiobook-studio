# Audiobook Studio

Нативное приложение для macOS 15+ на Apple Silicon. Интерфейс и движок — Swift,
генерация Qwen3-TTS работает через MLX Swift, ударения Silero — через C++/libtorch.
Python, pip и виртуальных окружений в приложении нет. FFmpeg, словари, модель
ударений и семь фоновых композиций входят в `.app`. При первом использовании
скачиваются только модели Qwen, с проверкой размера и SHA256.

На GitHub Python применяется только как инструмент сборки: экспортирует Silero
в TorchScript и упаковывает зависимости. Чистый пакет проверяется офлайн с пустой
домашней папкой: запускаются нативные Metal-ядра и загружаются обе модели ударений.
Проверка не синтезирует речь и не обрабатывает пользовательские книги.

## Работа с книгой

1. В настройках введите Ollama API key. Он сохраняется в системной Связке ключей
   macOS; ключ и настройки сохраняются между перезапусками и обновлениями приложения.
2. Выберите EPUB и папку результатов, нажмите верхнюю кнопку «Собрать автоматически»
   с волшебной палочкой: разметка, характеры, модели и сборка выполняются подряд.
   Модель уточняет неопределённые реплики; оставшиеся получают «Прочие голоса» без
   остановки сборки. Эти назначения сохраняются с низкой уверенностью для последующей правки.
3. Для пошаговой работы нажмите «Определить персонажей и расставить роли»:
   характеры тоже заполнятся автоматически. Рассказчик получает стандартный шаблон.
   Кнопка «Определить характеры персонажей» повторяет анализ. Запросы DeepSeek
   выполняются последовательно; веб-поиск Ollama включается отдельно.
4. Персонажи отображаются общим списком раскрывающихся карточек. При желании уточните возраст, характер, привычки, манеру речи и описание голоса.
   Основания и предположения доступны в карточке. LLM не меняет ID и разметку текста.
5. Для любой роли, включая рассказчика, можно загрузить собственный образец:
   чистая запись одного голоса 3–30 секунд и точный текст, произнесённый в записи.
   Он заменит VoiceDesign для этой роли; остальные голоса будут сгенерированы.
6. Выберите одну из семи штатных композиций или свой файл. Громкость по умолчанию 5%, трек зацикливается
   до конца книги. Музыку можно отключить. Выбранный трек копируется в проект книги.
7. «Собрать аудиокнигу и наложить на EPUB» создаст `result/audiobook.m4b` и
   `result/audiobook.epub`. Синхронизация/подсветка по предложениям требует
   EPUB3-читалки с Media Overlays. Безмузыкальная речь сохраняется отдельно.

«Генератор голосов» в боковой панели работает независимо от книги и LLM:
опишите голос, напишите тестовый текст, выберите вариант и запустите конструктор.
Загружается только VoiceDesign. После генерации можно прослушать пробу и сохранить
WAV вместе с JSON, содержащим точный текст и описание. При последующей загрузке
такого WAV в карточку персонажа текст подхватывается из соседнего JSON автоматически.
У каждой роли также есть «Прослушать образец»: свой загруженный голос воспроизводится
сразу; для нейросетевого голоса создаётся проба по текущему описанию. Эти пробы можно
сохранять отдельно или закреплять кнопкой «Использовать для персонажа»; сгенерированные голоса полной сборки сохраняются внутри проекта. Прослушивание происходит прямо
в приложении; повторное нажатие останавливает запись.

Нормализация текста, словарь + Silero, последовательная загрузка VoiceDesign и Base,
нормализация громкости по ролям и контроль длительности музыки сохранены из CLI.
Неопределённые роли автоматически уточняются моделью; оставшиеся получают «Прочие голоса». В GUI можно проверить реплики, найти их
по тексту и изменить говорящего. Изменяется только назначение роли; текст и
привязки EPUB сохраняются. Карточки и свои образцы сохраняются в проекте книги;
сгенерированные образцы сохраняются для повторной сборки; изменение описания голоса создаёт новый образец.

Скорость отображается в аудиосекундах на секунду синтеза (например 1,3×).
Прогноз оставшегося синтеза учитывает последние 12 фрагментов и объём оставшегося
текста. До первых замеров оценка отсутствует. Создание образцов, загрузка моделей,
нормализация и упаковка показываются отдельными этапами и не входят в этот прогноз.
Все обращения к LLM и веб-поиск строго последовательны. Запускается только одна задача.

В настройках можно включать значок в Dock и верхней панели macOS. Один из них
всегда остаётся доступным. Из верхней панели открывается окно и доступна остановка
работы. Переключатель «Обычный / Фоновый» работает во время сборки: macOS снижает
приоритет CPU и ввода-вывода, а прогноз времени учитывает измеренную скорость.
Это не ограничение памяти или мощности GPU. Настройки присутствия и приоритета
сохраняются между запусками. Иконка приложения: `assets/AppIcon.png`, `assets/AppIcon.icns`.

## Сборка и обновления

GitHub Actions собирает автономный ARM64 `.app` при каждом push в `main`.
Архив доступен в артефактах Actions; тег `v0.1.0` создаёт GitHub Release.
В релиз включаются ZIP и подписанный `appcast.xml`. Sparkle проверяет Ed25519-подписи
архива и ленты, поддерживает автоматическую проверку обновлений и установку.
Книги, пользовательские образцы, ключи, результаты и модели не хранятся в Git.

Постоянный ключ обновлений: публичная часть в `sparkle-public-key.txt`, закрытая —
в GitHub Actions secret `SPARKLE_PRIVATE_KEY`. Резервная копия в `.private/sparkle.key`
исключена из Git; сохраните её отдельно. Не генерируйте новый ключ для каждого релиза.
Этот ключ удостоверяет обновления, но не заменяет Apple Developer ID.
Текущие сборки имеют ad-hoc code signature, без нотарификации Apple.
Первый запуск может потребовать разрешения в настройках безопасности macOS.

Для разработчика: `brew install ffmpeg`, затем `bash scripts/package.sh`.
Тесты ядра: `STUDIO_CORE_ONLY=1 swift test --package-path native`.
Снимок исходного движка и его commit находятся в `backend/engine/UPSTREAM.txt`.

## Зависимости

SwiftUI/AppKit, Sparkle 2.9.6, Qwen3-TTS, MLX Audio Swift, Silero Stress/libtorch, FFmpeg.
Лицензии нативных зависимостей включены в `Contents/Resources/licenses`. FFmpeg собирается из Homebrew; его конфигурация
и соответствующие исходники доступны через `brew info --json=v2 ffmpeg` и
https://github.com/Homebrew/homebrew-core/blob/HEAD/Formula/f/ffmpeg.rb.
Штатная композиция «Свет лампы и страницы» включена по разрешению владельца проекта.

«Сохранить проект…» в меню «Файл» (⌘S) и главном окне создаёт один файл `.audiobookstudio`: книга, карточки и роли, загруженные голоса, выбранная музыка, настройки сборки и готовое аудио. Модели и API-ключ в файл не включаются. «Открыть проект…» (⌘O) распаковывает независимую рабочую копию: можно изменить голос и заново собрать книгу. Предыдущая сборка остаётся в папке `revisions` внутри проекта.

Пробы сгенерированных голосов автоматически воспроизводятся один раз и используют собственные реплики персонажа из книги: цель 120 знаков с пробелами, граница по слову или предложению до 150 знаков (примерно 10–13 секунд); короткие начальные реплики дополняются последующими репликами того же персонажа.

Перед ручной или автоматической сборкой открывается окно «Куда сохранить аудиокнигу?»: укажите место и имя новой папки для M4B и EPUB. Файл редактируемого проекта сохраняется отдельно через «Сохранить проект…». После сборки полный путь отображается в статусе и доступна кнопка «Папка аудиокниги».
